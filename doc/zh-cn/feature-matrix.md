# 共享行为和配置

本页描述可复用的引擎契约。应用模块选择、适配实现和接入历史属于应用仓库。
兼容规则见 [invariants.md](invariants.md)，完整 API 文档见
[functions/INDEX.md](functions/INDEX.md)。章节标签保留 API 页面使用的引用标识。

## A. WebDAV 配置与传输

应用提供远程路径和凭据。传输层提供 URL 规范化、Basic 认证和可注入的请求超时。
连接检查接受 207 和 404，配置往返保留未知键。

## B. 上传锁

远程 `.lock` 和本地 `.sync_base/upload_lock.json` 状态协调上传。
默认 TTL 为 60 秒，心跳为 20 秒。条件锁写入使用 ETag 且不重试；
调用方保留所有权和过期锁检查。

## C. 目录解析

PROPFIND 解析使用 `<(?:\w+:)?href>` 接受带命名空间和无前缀的 href 元素。
失败与空列表保持可区分。

## D. 重试策略

瞬态失败和服务器错误最多额外尝试两次，退避为 1 秒和 2 秒。
客户端错误和锁写入不重试。

## E. 记录合并

泛型三方合并接受领域回调和可选未知字段保留。相同的序列化内容抑制不必要的冲突。
领域专用复合键合并由应用负责。

### E4. 记录删除语义

| 场景 | 结果 | 冲突？ |
|---|---|---|
| 本地删除，远程与基线相同 | 排除 | 否 |
| 本地删除，远程修改 | 保留远程 | 否 |
| 远程删除，本地与基线相同 | 排除 | 否 |
| 远程删除，本地修改 | 保留本地 | 否 |
| 双方删除 | 排除 | 否 |
| 一方新增且无基线 | 包含 | 否 |
| 双方新增相同 ID 且无基线 | 最新 modifiedAt；相同则选择远程 | 否 |

修改优先于删除。共享合并测试固定这些语义。

## F. 未知 JSON 字段

提供模式驱动的递归保留和平铺未知字段合并。应用提供模式或模型回调，
并决定在合并时还是上传前保留未知字段。

## G. 同步编排

有序模块注册表提供文件、校验、合并、引用图像和变换。同步维护基线快照、明确的
待定冲突和粘性本地变更信号。最终化在上传前重新下载远程数据。默认逐文件收集
下载错误，可配置为遇错中止。图像仅按引用添加式同步。模块回调负责显示名称、
JSON 格式和确定的上传进度选择。

## H. 自动同步调度

调度器处理启动、恢复、周期和保存防抖触发，带执行中守卫。启动、恢复和周期同步
取消挂起的保存防抖。应用提供恢复和周期钩子、重载行为和备份触发。

## I. 基线快照

保留 `.sync_base` 格式和 UTC 时间戳。未知 JSON 字段在解析、合并和写入中保留。
路径和模块内容由应用负责。

## J. 备份

V2 捆绑保存原始模块 JSON 和 `_imageRefs`，旧 v1 使用 `_images`。内容寻址 blob
使用引用计数垃圾回收、默认 10 分钟宽限和遇不可解析中止行为。保留策略和每日
备份守卫可配置。恢复在写入前校验选中模块，并在首次写入前禁用自动同步。
可选合成 `images` 选择控制图像恢复。图像键接受裸名称和 `images/<name>`，
拒绝嵌套、绝对和穿越路径。探测限制默认为 4 MiB。

## K. 原子 I/O 和校验

同目录临时文件支持经过校验的原子替换。可选按所有者队列串行写入，不会全局
串行化无关文件。`DataModule.validate` 提供领域校验和类型化文件错误。

## L. 存储设置

保留 `storage_config.json` 键，包括 `autoBackupEnabled` 和 `backupRetentionDays`。
每日备份不持久化 `lastBackupAt` 键。应用专用设置迁移留在包外。

## M. ZIP 传输

导出使用注册表文件和平铺的 `images/<basename>` 条目。导入拒绝路径穿越，在写入前
分类条目。未知条目拒绝、严格 UTF-8 解码、写前校验和原子写入默认均为 true。
归档命名和导入后操作由应用提供。

## N. 面向用户的文字

保持共享引擎错误兼容，已接受的变化见 [invariants.md](invariants.md)。
本地化 UI 文案和数据派生的冲突名称由应用负责。

## O. 配置边界

应用注入存储根、模块注册表、远程路径、领域合并和校验回调、图像引用、变换、
归档命名和生命周期钩子。传输超时、备份保留、blob 宽限、探测大小和导入严格性
有明确默认值。签名见逐文件 API 页面。

## P. 接入文档

选用的模块、持久化适配器、领域策略和回归结果记录在应用自身文档中。
共享库不规定使用方名单。

## Q. 验证

单元测试和包自有合成注册表 golden 验证引擎行为、请求和格式。
修改共享契约前验证线上兼容性和应用回归。

## R. 隐私提醒与端点安全

首次启用同步前，应用显示共享提醒，用户确认前不发出任何请求；拒绝时不存储任何内容。
提醒列出应用上传的数据模块和可选内容、目标主机、服务器端加密说明，以及安全端点
策略给出的传输安全状态；发往公网主机的明文 HTTP 会额外警告。确认记录按设备保存，
带提醒版本，从不同步、备份或导出。已配置但未确认的同步报告为暂停，应用保留待同步
数据并明确显示暂停。线格式、远端布局、`.lock` 语义和冲突处理不变。

## S. 密钥通道

应用的 API Key 密钥文件（文件名由应用注入，例如 `transcribe_secrets.json`）位于应用目录，
但从不是数据模块，因此同步、备份和 ZIP 从不触及它。同步后，交换在同一服务器和远端目录上、
引擎 `.lock` 之外运行，且只在安全端点判定允许时进行；被拒绝的端点在两个方向都不发出请求。
密钥按键以 `updatedAt` 合并，后写优先，带墓碑；上传以下载时的 ETag 为条件（或仅创建），
收到 412 时恰好重读并重合并一次，若重读失败则不上传直接失败。强制上传和强制下载在各自方向
跳过合并。本地读取、合并和写入与密钥编辑共用一把应用内锁，持锁期间不发起网络请求；无法解析
的内容改名为 `<name>.unreadable-<UTC timestamp>`，I/O 错误是不作任何改动的类型化失败。
命名空间限定应用可读写的 id。
